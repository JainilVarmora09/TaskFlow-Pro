# TaskFlow Pro

TaskFlow Pro is a modern task management web application built using **HTML**, **CSS**, and **Vanilla JavaScript**. It helps users organize daily tasks with a clean, responsive, and user-friendly interface.

## Features
- Add, edit, and delete tasks
- Dark & Light mode
- Responsive design
- Search tasks
- Task categories
- Priority levels
- Due dates
- Progress tracking
- Statistics dashboard
- Confetti animation on task completion
- Local Storage support

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/JainilVarmora09/TaskFlow-pro.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional installation is required.
